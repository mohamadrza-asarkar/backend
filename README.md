# 🌾 مستندات کامل وب‌سرویس فروشگاه برنج و مشتقات (REST API با Mongoose و MongoDB)

یک بک‌اند قدرتمند، مدرن، ماژولار و بهینه‌سازی شده با **Node.js (ES Modules)**، **Express** و **Mongoose (MongoDB)** برای مدیریت و فروش انواع **برنج اعلا**، **نیم دانه برنج** و **ریز دانه برنج (لاشه و سرلاشه)** همراه با احراز هویت امن **JWT**، آپلود تصویر **Multer**، جستجوی بلادرنگ با **Query** و باز بودن کامل **CORS** برای تمامی دامنه‌ها.

## 🗂️ اسکیماها و ساختار داده‌ها

### ۱. محصول (`Product`):
محصولات شامل انواع **برنج**، **نیم دانه برنج** و **ریز دانه برنج** است:
- **`name`** (`String`): نام و عنوان محصول (مثال: `"برنج طارم هاشمی درجه یک گیلان (کیسه ۱۰ کیلوگرمی)"`)
- **`description`** (`String`): توضیحات کامل درباره عطر، پخت، خلوص، منطقه کشت و...
- **`price`** (`Number`): قیمت به تومان (مثال: `1350000`)
- **`isAvailable`** (`Boolean`): موجود بودن محصول در انبار (`true` یا `false`)
- **`reviews`** (`Array`): آرایه‌ای از نظرات و امتیازهای ثبت شده برای محصول
- **`countInStock`** (`Number`): تعداد موجودی در انبار
- **`image`** (`String`): تصویر محصول

### ۲. اسلاید (`Slide`):
- فقط شامل یک تصویر (**`image`**) است که از طریق **مالتر (Multer)** آپلود شده یا از طریق لینک ذخیره می‌شود.

### ۳. سبد خرید (`Cart`):
- شامل لیستی از چند محصول (**`products`**) به همراه تعداد (`quantity`) و قیمت کل.

### ۴. سفارش (`Order`):
- **`buyerName`** (`String`): نام و نام خانوادگی خریدار
- **`address`** (`String`): نشانی دقیق پستی جهت ارسال
- **`phone`** (`String`): شماره تماس خریدار
- **`products`** (`Array`): لیست اقلام خریداری شده
- **`totalPrice`** (`Number`): مبلغ کل سفارش
- **`status`** (`String`): وضعیت سفارش (`pending`, `processing`, `shipped`, `delivered`)

### ۵. نظر / دیدگاه (`Review`):
- **`sender`** (`String`): نام فرستنده نظر
- **`comment`** (`String`): متن و شرح دیدگاه
- **`rating`** (`Number`): امتیاز ثبت شده از ۱ تا ۵

## 🔍 مستندات API جستجو با کوئری (Search API)

برای جستجوی سریع و فیلتر روی محصولات برنج، نیم‌دانه و ریزدانه دو روش اختصاصی طراحی شده است:

### روش اول: اندپوینت اختصاصی جستجو (`/api/products/search`)
- **متد:** `GET`
- **آدرس:** `/api/products/search?q=عبارت_جستجو`
- **پارامترهای Query:**
  - `q`: کلمه مورد نظر برای جستجو در نام و توضیحات (مثال: `هاشمی`، `نیم دانه`، `ریز دانه`، `طارم`)
  - `isAvailable`: فیلتر وضعیت موجودی (`true` یا `false`)
  - `minPrice`: حداقل قیمت به تومان
  - `maxPrice`: حداکثر قیمت به تومان
  - `sortBy`: مرتب‌سازی (`price-asc`, `price-desc`, `newest`)

#### نمونه درخواست cURL:
```bash
# جستجوی نیم دانه برنج
curl -X GET "http://localhost:3000/api/products/search?q=%D9%86%DB%8C%D9%85%20%D8%AF%D8%A7%D9%86%D9%87"

# جستجوی برنج‌های موجود با حداکثر قیمت ۱ میلیون تومان
curl -X GET "http://localhost:3000/api/products/search?q=برنج&isAvailable=true&maxPrice=1000000"
```

## 📡 مستندات کامل اندپوینت‌ها

### ۱. محصولات (Products)

| روت | متد | دسترسی | توضیحات |
|---|---|---|---|
| `/api/products` | `GET` | عمومی | دریافت لیست محصولات با صفحه‌بندی و فیلتر |
| `/api/products/search` | `GET` | عمومی | **جستجوی پیشرفته با پارامتر کوئری `q`** |
| `/api/products/:id` | `GET` | عمومی | دریافت مشخصات کامل یک محصول و نظرات آن |
| `/api/products` | `POST` | مدیر (Admin) | افزودن محصول جدید برنج |
| `/api/products/:id` | `PUT` | مدیر (Admin) | ویرایش نام، قیمت یا موجودی محصول |
| `/api/products/:id` | `DELETE` | مدیر (Admin) | حذف محصول |

#### نمونه ایجاد محصول جدید (POST `/api/products`):
```json
{
  "name": "برنج دم سیاه صدری ممتاز گیلان (کیسه ۱۰ کیلو)",
  "description": "برنج فوق‌العاده معطر و دانه‌بلند دم‌سیاه، کشت اختصاصی آستانه اشرفیه",
  "price": 1600000,
  "isAvailable": true,
  "countInStock": 20,
  "image": "https://images.unsplash.com/photo-1586201375761-83865001e31c?w=800&q=80"
}
```

### ۲. اسلایدها (Slides & Multer)

| روت | متد | دسترسی | توضیحات |
|---|---|---|---|
| `/api/slides` | `GET` | عمومی | دریافت لیست تمام اسلایدها |
| `/api/slides` | `POST` | مدیر (Admin) | **آپلود تصویر با مالتر (Multipart) یا ارسال آدرس عکس (JSON)** |
| `/api/slides/:id` | `DELETE` | مدیر (Admin) | حذف اسلاید |

#### نمونه آپلود فایل با Multer (cURL):
```bash
curl -X POST http://localhost:3000/api/slides \
  -H "Authorization: Bearer YOUR_ADMIN_TOKEN" \
  -F "image=@/path/to/banner.jpg"
```

### ۳. سبد خرید (Cart)

| روت | متد | دسترسی | توضیحات |
|---|---|---|---|
| `/api/cart` | `GET` | عمومی / کاربر | مشاهده محتویات کارت و لیست چند محصول |
| `/api/cart/items` | `POST` | عمومی / کاربر | افزودن محصول برنج به سبد خرید |
| `/api/cart/items/:productId` | `PUT` | عمومی / کاربر | تغییر تعداد یک محصول در سبد |
| `/api/cart/items/:productId` | `DELETE` | عمومی / کاربر | حذف محصول از سبد خرید |
| `/api/cart` | `DELETE` | عمومی / کاربر | خالی کردن کامل سبد خرید |

#### نمونه افزودن به سبد (POST `/api/cart/items`):
```json
{
  "productId": "prod-1",
  "quantity": 2
}
```

### ۶. احراز هویت (Auth)

| روت | متد | دسترسی | توضیحات |
|---|---|---|---|
| `/api/auth/register` | `POST` | عمومی | ثبت‌نام کاربر جدید با هش پسورد Bcrypt |
| `/api/auth/login` | `POST` | عمومی | ورود کاربر و دریافت توکن JWT Bearer |
| `/api/auth/me` | `GET` | احراز هویت شده | دریافت مشخصات پروفایل کاربر فعلی |

#### اطلاعات حساب‌های آزمایشی موجود:
- **مدیر کل (Admin):**
  - ایمیل: `admin@store.ir`
  - رمز عبور: `admin123456`
- **کاربر عادی (User):**
  - ایمیل: `user@store.ir`
  - رمز عبور: `user123456`

## 🚀 راهنمای اجرا و راه‌اندازی

```bash
# ۱. نصب پیش‌نیازها
npm install

# ۲. اجرای سرور
npm start

# ۳. اجرای در محیط توسعه (Dev Mode)
npm run dev
```

سرور روی پورت `3000` آماده به کار خواهد بود:
- آدرس پایه API: `http://localhost:3000/api`
- مستندات زنده OpenAPI: `http://localhost:3000/api/docs/openapi.json`
- کالکشن آماده Postman: `http://localhost:3000/api/docs/postman.json`
- بررسی وضعیت سرور (Health): `http://localhost:3000/api/health`
