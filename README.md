# 🌾 مستندات وب‌سرویس فروشگاه تخصصی برنج و مشتقات (REST API)

یک بک‌اند قدرتمند، مدرن، ماژولار و بهینه‌سازی شده با **Node.js (ES Modules)**، **Express** و **Mongoose (MongoDB)** برای مدیریت و فروش انواع **برنج اعلا**، **نیم دانه برنج** و **ریز دانه برنج (لاشه و سرلاشه)** همراه با احراز هویت امن **JWT بر پایه شماره موبایل و پسورد**، آپلود تصویر **Multer**، جستجوی بلادرنگ با **Query**، امنیت ریت لیمیت (**Rate Limiting**) و باز بودن کامل **CORS** برای تمامی دامنه‌ها.

## 🗂️ اسکیماها و ساختار داده‌ها

### ۱. محصول (`Product`):
محصولات شامل انواع **برنج**، **نیم دانه برنج** و **ریز دانه برنج** است:
- **`name`** (`String`): نام و عنوان محصول (مثال: `"برنج طارم هاشمی درجه یک گیلان (کیسه ۱۰ کیلوگرمی)"`)
- **`description`** (`String`): توضیحات کامل درباره عطر، پخت، خلوص، منطقه کشت و...
- **`price`** (`Number`): قیمت به تومان (مثال: `1350000`)
- **`isAvailable`** (`Boolean`): موجود بودن محصول در انبار (`true` یا `false`)
- **`countInStock`** (`Number`): تعداد موجودی در انبار
- **`image`** (`String`): تصویر محصول (لینک یا فایل آپلود شده)
- **`reviews`** (`Array`): آرایه‌ای از نظرات و امتیازهای ثبت شده برای محصول

### ۲. اسلاید (`Slide`):
- فقط شامل یک تصویر (**`image`**) است که از طریق **مالتر (Multer)** آپلود شده یا از طریق لینک ذخیره می‌شود.

### ۳. سبد خرید (`Cart`):
- شامل لیستی از چند محصول (**`products`**) به همراه تعداد (`quantity`) و قیمت کل.

### ۴. سفارش (`Order`):
- **`buyerName`** (`String`): نام و نام خانوادگی خریدار
- **`address`** (`String`): نشانی دقیق پستی جهت ارسال
- **`phone`** (`String`): شماره تماس همراه خریدار (مثال: `"09121234567"`)
- **`products`** (`Array`): لیست اقلام خریداری شده
- **`totalPrice`** (`Number`): مبلغ کل سفارش
- **`status`** (`String`): وضعیت سفارش (`pending`, `processing`, `shipped`, `delivered`, `cancelled`)

### ۵. نظر / دیدگاه (`Review`):
- **`productId`** (`String`): شناسه محصول
- **`sender`** (`String`): نام فرستنده نظر
- **`comment`** (`String`): متن و شرح دیدگاه
- **`rating`** (`Number`): امتیاز ثبت شده از ۱ تا ۵

### ۶. کاربر (`User`):
- **`name`** (`String`): نام و نام خانوادگی
- **`phone`** (`String`): شماره موبایل ۱۱ رقمی (شناسه اصلی و یکتا)
- **`password`** (`String`): رمز عبور امن هش شده
- **`role`** (`String`): نقش کاربر (`user` یا `admin`)
- **`address`** (`String`): نشانی پیش‌فرض

## 🔐 احراز هویت با شماره موبایل و پسورد

احراز هویت و ثبت‌نام در سامانه به صورت کاملاً امن با **شماره تلفن همراه (Phone)** و **رمز عبور (Password)** انجام می‌شود.

### ۱. ثبت‌نام کاربر جدید:
`POST /api/auth/register`
```json
{
  "name": "علی رضایی",
  "phone": "09123456789",
  "password": "mySecurePassword123"
}
```

### ۲. ورود به حساب کاربری:
`POST /api/auth/login`
```json
{
  "phone": "09123456789",
  "password": "mySecurePassword123"
}
```
پاسخ سرور شامل توکن دسترسی `token` به فرمت JWT خواهد بود که برای دسترسی به اندپوینت‌های محافظت‌شده باید در هدر ارسالی قرار گیرد:
```http
Authorization: Bearer <YOUR_JWT_TOKEN>
```

## 🔍 مستندات API جستجو با کوئری (Search API)

جستجوی آنی و پیشرفته محصولات با پارامترهای کوئری:

```http
GET /api/products/search?q=هاشمی
```
یا با اعمال انواع فیلترها و مرتب‌سازی:
```http
GET /api/products?search=هاشمی&isAvailable=true&minPrice=500000&maxPrice=1500000&sortBy=price-asc&page=1&limit=10
```

## 📡 مستندات کامل اندپوینت‌ها (API Endpoints)

پیشوند تمام روت‌ها: `/api`

### ۱. محصولات (`/api/products`)
| روت | متد | دسترسی | توضیحات |
|---|---|---|---|
| `/api/products` | `GET` | عمومی | لیست محصولات برنج با صفحه‌بندی و فیلتر |
| `/api/products/search` | `GET` | عمومی | جستجو با کوئری `?q=عبارت` |
| `/api/products/:id` | `GET` | عمومی | دریافت جزئیات یک محصول با نظرات |
| `/api/products` | `POST` | Admin | ایجاد محصول برنج جدید |
| `/api/products/:id` | `PUT` | Admin | ویرایش اطلاعات محصول |
| `/api/products/:id` | `DELETE` | Admin | حذف محصول |

### ۲. اسلایدها و آپلود تصویر (`/api/slides`)
| روت | متد | دسترسی | توضیحات |
|---|---|---|---|
| `/api/slides` | `GET` | عمومی | مشاهده لیست تمام اسلایدها |
| `/api/slides` | `POST` | Admin | آپلود اسلاید با Multer (فیلد `image`) |
| `/api/slides/:id` | `DELETE` | Admin | حذف اسلاید |

### ۳. سبد خرید (`/api/cart`)
| روت | متد | دسترسی | توضیحات |
|---|---|---|---|
| `/api/cart` | `GET` | عمومی/کاربر | دریافت محتوای سبد خرید |
| `/api/cart/items` | `POST` | عمومی/کاربر | افزودن محصول با `{ productId, quantity }` |
| `/api/cart/items/:productId` | `PUT` | عمومی/کاربر | تغییر تعداد محصول در سبد |
| `/api/cart/items/:productId` | `DELETE` | عمومی/کاربر | حذف محصول از سبد |
| `/api/cart` | `DELETE` | عمومی/کاربر | خالی کردن کامل سبد خرید |

### ۴. سفارشات (`/api/orders`)
| روت | متد | دسترسی | توضیحات |
|---|---|---|---|
| `/api/orders` | `POST` | عمومی/کاربر | ثبت سفارش با مشخصات خریدار (نام، آدرس، تلفن) |
| `/api/orders` | `GET` | لاگین | لیست سفارشات کاربر |
| `/api/orders/:id` | `GET` | عمومی/کاربر | مشاهده جزئیات سفارش با شناسه یا شماره سفارش |
| `/api/orders/:id/status` | `PUT` | Admin | تغییر وضعیت سفارش |

### ۵. نظرات و دیدگاه‌ها (`/api/reviews`)
| روت | متد | دسترسی | توضیحات |
|---|---|---|---|
| `/api/reviews?productId=xxx` | `GET` | عمومی | نظرات مربوط به یک محصول |
| `/api/reviews` | `POST` | عمومی/کاربر | ثبت نظر با `{ productId, sender, comment, rating }` |
| `/api/reviews/:id` | `DELETE` | Admin | حذف نظر نامناسب |

### ۶. پنل مدیریت (`/api/admin`)
| روت | متد | دسترسی | توضیحات |
|---|---|---|---|
| `/api/admin/dashboard` | `GET` | Admin | آمار درآمد، سفارش‌ها و کاربران |
| `/api/admin/users` | `GET` | Admin | لیست تمامی کاربران ثبت‌نامی |
| `/api/admin/users/:id/role` | `PUT` | Admin | تغییر سطح دسترسی کاربر |
| `/api/admin/users/:id/toggle-status` | `PUT` | Admin | فعال/غیرفعال‌سازی کاربر |
| `/api/admin/orders` | `GET` | Admin | مشاهده تمامی سفارشات سامانه |

## 🛡️ امنیت و Rate Limiting

برای جلوگیری از حملات Brute-Force و سوءاستفاده، محدودیت نرخ درخواست به صورت هوشمند پیاده‌سازی شده است:
- **مسیرهای احراز هویت (`/api/auth/*`):** حداکثر ۲۵ درخواست در هر ۱۵ دقیقه برای هر IP.
- **سایر مسیرهای API (`/api/*`):** حداکثر ۲۰۰ درخواست در هر ۱۵ دقیقه برای هر IP.

## 🚀 راهنمای اجرا و راه‌اندازی

```bash
# ۱. نصب وابستگی‌ها
npm install

# ۲. اجرای سرور
npm start

# ۳. اجرای محیط توسعه با لایو ریلود
npm run dev
```

سرور روی پورت `3000` بالا می‌آید:
- آدرس روت API: `http://localhost:3000/api`
- مستندات زنده OpenAPI: `http://localhost:3000/api/docs/openapi.json`
- کالکشن آماده Postman: `http://localhost:3000/api/docs/postman.json`
- بررسی وضعیت سرور (Health Check): `http://localhost:3000/api/health`
